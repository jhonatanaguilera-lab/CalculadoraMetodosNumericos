# CalculadoraMetodosNumericos
# Autor: Jhonatan Aguilera
# POO 2026
La CalculadoraMetodosNumericos es una herramienta que busca solucionar un problema en la materia de Metodos Numericos. A la hora de estudiar es complicado dar con el resultado exacto de los ejercicios, la CalculadoraMetodosNumericos busca solucionar esto con una interfaz intuitiva y facil de utilizar, sin ser experto en Python.
Debido a que al empezar a estudiar ya que se debe recordar y aprender la implementacion del lenguaje Python para Metodos Numericos, junto con la problemática que a veces no se cuenta con las respuestas exactas o correctas del problema.
Implementando cada una de las Rutinas proporcionadas por la cátedra, la CalculadoraMetodosNumericos resuelve este problema proporcionando una interfaz intuitiva y fácil de utilizar para obtener la respuesta buscada, de manera a que los alumnos puedan verificar con total seguridad las respuestas a la que deben de llegar en los ejercicios.
La calculadora cuenta por ahora con 3 Unidades importantes en Metodos Numericos: Resolucion de sistemas lineales, Cálculo de Raíces de ecuaciones, Integración Numérica con datos tabulados o funcionales.
Se utilizó la gran herramienta de la IA como apoyo para reducir los errores al mínimo y llevar a cabo un proyecto satisfactorio.
El proyecto cuenta con todos los elementos y requisitos pedidos por la cátedra de POO 2026 para el Proyecto supervisado.
