# CalculadoraMetodosNumericos
La CalculadoraMetodosNumericos es una herramienta que busca solucionar un problema a la hora de estudiar  la materia de Metodos Numericos. A la hora de estudiar es complicado dar con el resultado exacto de los ejercicios, la CalculadoraMetodosNumericos busca solucionar esto con una interfaz intuitiva y facil de utilizar, sin ser experto en Python.
